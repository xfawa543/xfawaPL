# How to Write a HelloWorld Program?
First, create a file with the extension **.xf**. You can choose any name, for example, HelloWorld.xf. Double-click the file to open it with Visual Studio Code. If you don’t have Visual Studio Code, you can use Notepad instead.

Open it with Visual Studio Code or Notepad and write the following:
```

#HelloWorld {
fn main() {
print("HelloWorld")
}
}

```

Then, enter:
```

.\xfawac.exe HelloWorld.xf -o HelloWorld.exe

```

Wait a moment, and then enter:
```

.\HelloWorld.exe

```

If it runs successfully, "HelloWorld" will appear. Congratulations—you’ve learned how to write a HelloWorld program in xfawa! Go ahead and try it out!
