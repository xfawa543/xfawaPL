# xfawa Programming Language

xfawa 是一门处于活跃开发中的实验性编译型编程语言。

该项目探索语言结构、可扩展性以及面向 AI 的编程工作流的新方法。

---

🚀 项目愿景

xfawa 旨在探索：

- 块优先的语言设计
- 可读且结构化的语法
- 面向 AI 友好的代码生成
- 通过 LLVM 实现原生代码编译
- 语言的可扩展性与实验性

该语言目前处于 Alpha 阶段，可能会发生重大变化。

---

✨ 特性

**块优先设计**

块是 xfawa 中的基础结构。

示例：

#application {
    fn main() {
        print("Hello World")
    }
}

与传统语言主要将块用于作用域控制不同，xfawa 探索将块作为语言的核心组织架构。

---

**编译型语言**

xfawa 被设计为一门编译型语言。

源代码通过 LLVM 转换为原生机器码，而非由解释器执行。

---

**面向 AI 友好的语法**

该语言强调结构化且可预测的语法。

目标是让代码对于开发者以及 AI 辅助工具来说更易于阅读、生成和理解。

---

**实验性 Mods 系统**

xfawa 包含一个实验性的 mods 系统，允许在编译期间进行源代码转换。

可能的用途包括：

- 语法扩展
- 语言实验
- 编译器扩展
- 自定义代码转换

mods 系统正处于活跃研究中，未来版本可能会有重大演变。

👤 创始人寄语

xfawa 最初是一个个人的编译器实验，后来逐渐演变成一个编程语言项目。

该语言仍在演进，许多想法正在积极测试和完善中。

xfawa 不拘泥于现有的语言惯例，而是专注于探索语言结构和可扩展性的新方法。
