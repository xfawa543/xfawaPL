# xfawa Programming Language

xfawa 是一个正在开发中的实验性编译型编程语言项目，目标是探索一种：

- 语法简洁但结构可扩展  
- 高性能执行（基于 LLVM）  
- 支持可扩展语法系统（mods）  
- 轻量运行时设计  

项目目前仍处于早期开发阶段（alpha）。

---

## 🚀 项目目标

xfawa 不是脚本语言，而是一个编译型语言设计实验项目。

核心目标包括：

### 1. 编译型语言设计
xfawa 在设计上属于编译型语言，源代码会被编译为本地机器码，而不是解释执行。

### 2. 语法设计探索
xfawa 的语法目标是易读且可扩展，但不绑定任何现有语言模型。

### 3. 高性能执行
通过 LLVM 将 xfawa 编译为本地机器码，以获得接近原生语言的性能。

### 4. mods 语法扩展系统（核心特性）
mods 系统允许在编译前对语法进行扩展或重写，使语言具备一定程度的可定制能力。

### 5. 轻量运行时
尽量减少外部依赖，将标准库与编译器分发包进行整合。

## 🧩 mods 系统

mods 是 xfawa 的核心机制，用于在编译早期阶段修改源码结构。

它可以用于：

- 语法扩展  
- 语法糖实现  
- 实验性语言特性验证  

目标是：

> 在不修改编译器核心的情况下扩展语言能力。

## 👤 创始人寄语

这个项目最开始只是一个编译器实验，并不是一个完整的语言设计计划。

mods 系统也是在开发过程中逐渐形成的，而不是一开始就设计好的结构。

项目仍然很早期，也可能会不断变化，但我希望它至少保留一个核心想法：

> 语言本身应该是可以被扩展的，而不是固定不变的规则集合。
