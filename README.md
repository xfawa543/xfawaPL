## 🛠️ Quick Start

### Install Compiler

```bash

git clone "https://github.com/xfawa543/xfawaPL"

cd xfawaPL
```

### Your First Program
Create `hello.xf`:
```
#Welcome {
   fn main() {
     print("Welcome to a new programming paradigm")
     print("Where complexity serves a purpose")
     }
}
```

Compile & run:
```./xfawac0 hello.xf -o hello```
```./hello```


## 🎯 Technical Highlights

### **1. Minimal Syntax**
- No semicolons, no ceremonial type declarations
- Focus on logic, not syntax rituals

### **2. Zero-Dependency Compilation**
- Pure C compiler, no runtime requirements
- Generates native binaries, direct execution

### **3. Cross-Platform Native**
- Windows native support
- Linux/macOS Supporting unknown!
- No VM or interpreter overhead

## 📚 Language Specification

### Basic Structure
```
#ProgramName {
 fn main() {
   // Your logic here
    print("Simplicity is power")
    }
}
```


### Currently Supported
- ✅ Program structure and `main` function
- ✅ `print` statements
- ✅ Variables and basic arithmetic
- ✅ `if/else` conditional logic
- ✅ Cross-platform compilation
